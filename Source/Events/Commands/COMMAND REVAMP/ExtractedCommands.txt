**All Commands**
- affixinfo [[lane #] (1-17)] - Displays current round affixes or affixes for a specific lane.
- animate [[index]] - Set unit animation by index.
- apm [] - Displays your APM for ACTIVE game time. (not counting intermissions)
- automt [[seconds] (20.00 default)] - Automatically applies this extra time at the start of each round. Limit is 60 seconds.
- clear [] - Clears your screen.
- color [[color]] - Sets the color of your kitty to the passed color parameter.
- colors [] - Display all available colors.
- disco [[on][off]] - Toggle disco mode.
- error [[on][off]] - Turns the error prompts off or on
- firstperson [] - Toggle first person camera.
- getdate [] - Gets the current date, time, day, month, etc.
- glow [[true/false]] - Toggle unit glow.
- help [[topic]] - Displays all available commands for the passed parameter topic.
- jackpot [] - Tells the number of jackpots all players have recieved this game.
- kc [] - Kicks yourself from the game.
- kibble [] - Displays the kibble collected by each player.
- kibblecurrency [[resolvePlayerId]] - Gets the Kibble Currency information on the given player.
- kick [[playerNumber]] - Initiate a votekick against a player.
- komotocam [] - Toggle KomotoCam.
- lockcamera [] - Locks your camera to your unit. Can also do ctrl + C.
- mirror [] - Toggle mirror mode.
- moretime [] - Adds 20 secondsd to the round timer. Can only happen once per round.
- music [] - Opens the music frame.
- names [] - Hides all floating name tags.
- nochain [] - Lets you opt out of the chained together event.
- overheadcam [] - Gives an overhead view.
- personalbests [[resolvePlayerId]] - Gets personal best stats of the passed parm player, if no parm then yourself.
- reset [] - Resets your camera to their default settings.
- resetmytournamentdata [] - Resets your Tournament Data
- rewards [] - Opens the rewards frame.
- rtr [[on/off] [player]] - Set RTR mode on/off.
- save [] - Save your current game stats.
- savedvc [] - Sets you to your previously last saved vortex color if you have one.
- setcolor [[rgb]] - Set your kitty vertex color to the passed red-green-blue values. (-sc 112, 52, 92)
- shop [] - Opens the shop frame.
- spincam [[speed]] - Toggle SpinCam.
- stats [[resolvePlayerId]] - Gets the game stats of the passed parm player, if no parm then yourself.
- team [[team #]] - Assigns you to the provided team arg #, (TEAM MODE ONLY)
- times [[player] [difficulty]] - Gets fastest overall times of the passed parm player and difficulty, if no parm then yourself and current difficulty.
- voteend [] - Initiate a vote to end the round (Solo Tournament Only).
- watcher [] - Removes all units from game and you become an observer/spectator.
- wild [] - Set your kitty to a random vertex color.
- wolfinfo [[lane #] (1-17)] - Displays the total wolf count or the wolf count for a specific lane.
- yes [] - Vote yes for the current vote.
- zoom [[xxxx]] - Adjust the camera zoom level to the passed parameter.

- gold [[amount][resolvePlayerId]] - Gives an [amount] of gold to the [resolvePlayerId]s

- mem [] - Prints debug names.
- movespeed [[speed] [resolvePlayerId]] - Sets the absolute move speed of the passed player, or yourself if no player is provided.
- noend [[on/off]] - Game won't end if turned on and all kitties die.
- observer [[resolvePlayerId]] - Forces a player into observer mode.
- pauseround [] - Pauses the round timer.

- playersperteam [[# Allowed Per Team]] - Sets the maximum # of people allowed per team to passed parm.
- removeaffix [[affix]] - Removes the specified affix from the currently selected wolf.

- resetcooldowns [[resolvePlayerId]] - Resets the cooldowns of the selected unit.
- resettournamentdata [[resolvePlayerId]] - Resets the resolvePlayerId Tournament Data
- restart [] - Restarts the current round and time to 0:00
- revive [] - Revives yourself.
- reviveto [[resolvePlayerId]] - Revives your hero to another hero, with the same facing angle.
- roundset [[round]] - Sets the current round.
- sendtostart [[resolvePlayerId]] - Sends the passed player to the start
- setcommandtier [[resolvePlayerId] [CommandTier]] - Sets the CommandTier level of the passed ResolvePlayerId
- setseason [[season]] - Sets the current season.
- sharecontrol [[resolvePlayerId] [on/off]] - Sets whether or not to force the player to share control [default: off]
- shareforcecontrol [[sharingPlayer] [sharedWithPlayer] [on/off]] - Sets whether or not to force the player to share control [default: off]
- slidespeed [[speed] [player]] - Sets the absolute slide speed of the passed player, or yourself if no player is provided.
- spawnkibble [[numberOfKibble]] - Spawns {int #} of kibbles 
- spawnlocation [] - Moves all kitties to the spawn location.
- speededit [[on/off] [resolvePlayerId]] - Turns on RTR and sets move speed to 800 for the specified player.
- stat [[stat] [value] [player?]] - Sets the specified game stat for the resolved player.
- summon [[resolvePlayerId]] - Revives another hero to yours, with the same facing angle.
- teammove [[resolvePlayerId] [Team #]] - Swaps the passed resolvePlayerId to the provided Team #, no restrictions
- time [[time] [value] [player?]] - Sets the specified game time for the resolved player.
- unpauseround [] - Unpauses the round timer.
- victoryarea [[true][false]] - Disables or enables victory area according to passed parm or flips it.
- wolfeffects [[true][false]] - Disables the wolves overhead ! effects
- wolfpause [[on][off]] - Pauses selected wolf. Defaults to [on]
- wolfshare [[on][off]] - Gives you control of all the wolves.
